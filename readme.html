Northstone Trailhead Landing Page

Overview

This project is a custom WordPress landing page built for the fictional Northstone outdoor gear brand and its Trailhead daypack product launch.

The page was developed from a written creative specification and implemented as a custom WordPress theme using a lightweight starter theme foundation.

Features

  • Full-width hero section with call-to-action
  • Three-column feature strip
  • Interactive product gallery with thumbnail navigation and swipe support
  • Dynamic testimonials powered by a custom post type and ACF
  • Email capture and footer call-to-action
  • Fully responsive layout
  • Custom styling based on the supplied brand guidelines

Technologies Used

  • WordPress
  • PHP
  • HTML5
  • CSS3
  • JavaScript
  • Advanced Custom Fields (ACF)
