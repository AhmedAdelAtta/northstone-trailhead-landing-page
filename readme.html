# Northstone Trailhead Landing Page ## Overview This project is a custom WordPress landing page built for the fictional **Northstone** outdoor gear brand and its **Trailhead Daypack** product launch. The page was developed from a written creative specification and implemented as a custom WordPress theme using a lightweight starter theme foundation. --- ## Features - Full-width hero section with call-to-action - Three-column feature strip - Interactive product gallery with thumbnail navigation and swipe support - Dynamic testimonials powered by a custom post type and Advanced Custom Fields (ACF) - Email capture and footer call-to-action - Fully responsive layout - Custom styling using the supplied brand color palette --- ## Technologies Used - **WordPress** - **PHP** - **HTML5** - **CSS3** - **JavaScript** - **Advanced Custom Fields (ACF)** --- ## Dynamic Content ### Hero Section - Hero background image ### Features Each feature contains: - Title - Icon - Description ### Product Gallery - Dynamic gallery images managed through ACF ### Testimonials Powered by a custom post type: - Customer name - Customer image - Quote content - Star rating ### Footer CTA - Editable call-to-action content - Email capture field --- ## Responsive Design Mobile behavior was not defined in the original specification and was intentionally designed and implemented to provide an optimal experience across devices. Responsive considerations include: - Mobile-friendly feature layout - Touch-enabled gallery interactions - Responsive typography and spacing - Optimized call-to-action sections - Adaptive image sizing and layout behavior --- ## Brand Guidelines The landing page follows the supplied Northstone brand palette: - **Moss Green:** `#3A4A3F` - **Stone:** `#E8E3D8` - **Burnt Orange:** `#C1622D` --- ## Author **Ahmed Adel Youssef** Senior WordPress Developer Full-Stack Web Developer LinkedIn: https://linkedin.com/in/ahmedadelyoussef88
